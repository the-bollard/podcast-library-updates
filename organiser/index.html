Organise episodes in one go.

Rename arcs, select multiple episodes and move them wherever they belong. Nothing changes on your phone until you import the finished file.

  1. In the Podcasts Android app, open Options → Settings → Export library for website.
  2. Open that JSON file here, then organise as many episodes as you like.
  3. Choose Download changes and import the new JSON through Settings → Import edited organisation.
